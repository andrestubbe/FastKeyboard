# FastKeyboard Reference Manual

`FastKeyboard` is the ultra-low latency Win32 RawInput keyboard interception, multi-keyboard hardware tracking, and window-focus gating engine of the FastJava ecosystem.

---

## 1. Core Vocabulary

* **RawInput (`WM_INPUT`)**: Intercepts unaccelerated physical keystrokes directly from the Win32 HID subsystem before standard OS keyboard translation, repeat buffers, or layout modifications.
* **Native Focus Gating**: Natively verifies `GetForegroundWindow()` inside the C++ message loop. When bound to an `HWND`, background keystrokes are dropped immediately with 0 JNI traversals and 0 JVM heap allocations.
* **Immutable Hardware Make Codes**: Reports the physical scan code generated by the keyboard controller alongside the translated Windows Virtual-Key code (`VKey`) and Unicode character.
* **Multi-Device Tracking**: Distinguishes independent physical keyboards, macro pads, and barcode scanners using stable OS hardware handles (`hDevice`).

## 2. Java API Reference

### Interface: `fastkeyboard.FastKeyboard`
The primary interface for managing keyboard interception lifecycles. Implements `AutoCloseable`.

#### Factory Methods
- `public static FastKeyboard open()`  
  Creates a new global FastKeyboard listener capturing all desktop keystrokes.
- `public static FastKeyboard openForWindow(long targetWindowHandle)`  
  Creates a window-bound keyboard listener that only dispatches keystrokes when the specified `HWND` has foreground focus.
- `public static long getConsoleWindow()`  
  Retrieves the native Win32 console window handle (`HWND`) if running inside a Windows console host.

#### Event Capture & Window Binding
- `public void startListening(FastKeyboardListener listener)`  
  Starts the background native Win32 message pump thread and begins dispatching raw keystroke events.
- `public void stopListening()`  
  Stops the background message pump thread and unregisters native hooks.
- `public void bindToWindow(long targetWindowHandle)`  
  Focus-gates capture to the specified window handle. Pass `0` to restore global capture.
- `public void unbindFromWindow()`  
  Restores global input interception across all desktop windows.
- `public boolean isListening()`  
  Returns `true` if the background listener thread is currently active.
- `public boolean isWindowBound()`  
  Returns `true` if keystroke capture is currently restricted to a specific window.
- `public long getBoundWindow()`  
  Returns the currently bound window handle (`HWND`), or `0` if listening globally.
- `public void close()`  
  Closes the keyboard instance, halts the listener, and releases unmanaged native resources.

#### Device Querying
- `public List<KeyboardDevice> getConnectedDevices()`  
  Retrieves an immutable list of all physically attached HID keyboard hardware devices.

### Interface: `fastkeyboard.FastKeyboardListener`
High-frequency functional callback receiving raw hardware keystroke packets:

```java
void onKeyEvent(long deviceHandle, int vKey, int makeCode, boolean isPressed, boolean isE0, long timestamp, String keyChar);
```
- `deviceHandle`: Native OS handle of the physical keyboard controller.
- `vKey`: Windows Virtual-Key code (see [`Keys`](#class-fastkeyboardkeys)).
- `makeCode`: Hardware scan code generated by the keyboard hardware.
- `isPressed`: `true` for key press (down), `false` for key release (up).
- `isE0`: `true` if the key is an extended key (e.g. right Alt, navigation arrow keys, numpad Enter).
- `timestamp`: System message timestamp in milliseconds.
- `keyChar`: Translated Unicode text representation (e.g. `'a'`, `'@'`), or `null`/empty for non-character keys.

---

### Record: `fastkeyboard.KeyboardDevice`
Immutable representation of a physical keyboard hardware device:

- `public long handle()` — Native OS device handle (`HANDLE`).
- `public String name()` — Human-readable or system identifier for the device.
- `public String devicePath()` — Full OS device interface path.

---

### Class: `fastkeyboard.Keys`
Complete catalog of Windows Virtual-Key code constants and utility methods:

- **Key Code Constants**: `Keys.VK_A` - `Keys.VK_Z`, `Keys.VK_0` - `Keys.VK_9`, `Keys.VK_F1` - `Keys.VK_F24`, `Keys.ESCAPE`, `Keys.RETURN`, `Keys.SPACE`, `Keys.TAB`, `Keys.CONTROL`, `Keys.SHIFT`, `Keys.MENU` (Alt), `Keys.LWIN`, `Keys.RWIN`.
- **Key Name Resolution**:
  - `public static String getName(int vKey)` — Resolves a virtual key code to its readable string representation (e.g. `"ESCAPE"`, `"RETURN"`, `"SPACE"`).

## 3. Platform & Hardware Guarantees

* **Zero GC Overhead**: Keystroke dispatching executes without per-event object allocations or garbage collection pressure.
* **Sub-Microsecond Dispatch**: Measured native dispatch latency under 350 ns per event.
* **Dedicated Message Pump**: Independent background Win32 message-only window (`HWND_MESSAGE`) isolates keyboard processing from UI rendering threads.
